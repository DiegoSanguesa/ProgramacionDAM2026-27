# 💻 Fundamentos de Programación (Java) — DAM

Este repositorio contiene los apuntes, ejercicios, prácticas y proyectos desarrollados durante el módulo profesional de **Fundamentos de Programación** del Ciclo Formativo de Grado Superior en **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

---

## 🎯 Objetivos del Módulo

* Comprender la lógica de programación y la resolución algorítmica de problemas.
* Dominar la sintaxis y características avanzadas del lenguaje **Java**.
* Aplicar los principios del paradigma de **Programación Orientada a Objetos (POO)**.
* Trabajar con estructuras de datos dinámicas, colecciones y algoritmos de ordenación/búsqueda.
* Gestionar la lectura y escritura de información en ficheros y persistencia básica de datos.
* Aplicar buenas prácticas de desarrollo: código limpio, gestión de excepciones y control de versiones con Git.

## ⚙️ Cómo Clonar y Ejecutar

1. **Clonar este repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/fundamentos-programacion-dam.git
   ```

2. **Abrir el proyecto:**
   * Abre tu IDE preferido (IntelliJ IDEA / Eclipse / VS Code).
   * Selecciona la carpeta raíz o subcarpeta del proyecto que quieras ejecutar.
   * Asegúrate de tener configurado el **JDK 17** (o superior).

3. **Ejecución:**
   * Localiza la clase que contiene el método `public static void main(String[] args)` y ejecútala.
